# HR Analytics Dashboard

## Project Overview
Interactive HR Analytics Dashboard built using Power BI to analyze employee attrition, workforce demographics, salary trends, and job satisfaction.

## Key KPIs
- Total Employees
- Active Employees
- Attrition Rate
- Average Salary
- Average Age

## Dashboard Features
- Employee Distribution by Department
- Attrition Analysis
- Gender Distribution
- Age Group Analysis
- Average Salary by Job Role
- Job Satisfaction Analysis

## Tools Used
- Power BI
- Power Query
- DAX
- Excel
